P2 — Refresh preserves My Domains list state FLAKE / TIMING
View Root Cause & Fix
Symptom: TimeoutError: locator.waitFor: Timeout 30000ms exceeded waiting for iframe[src*="mpContainerStaticController"].contentFrame().locator(':text("Domains")').
Where: account-level-gate.spec.ts:96 — after page.reload().
Root Cause: After page.reload(), the dashboard chrome remounts the mpContainerStaticController iframe asynchronously. In headed mode the remount took longer than 30s; the same test passed in 17.5s in headless. Pure timing / flake.
Suggested Fix: Bump iframe re-attach timeout to 60s after reload, then wait an extra networkidle cycle before searching for content. Also: prefer fl.locator(':text("Domains")').first().waitFor({ timeout: 60_000 }) instead of capturing a fresh fl2 — the existing FrameLocator handle is stable across reloads.
